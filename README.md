This week focused on the foundational concepts of integrating Vue.js into an HTML page and establishing a reactive data model. I learned how to initialize a Vue application instance and mount it directly to the DOM. By utilizing declarative rendering, I could bind data to the UI using mustache syntax to dynamically display text. Furthermore, applying attribute binding via the v-bind directive allowed me to dynamically link HTML attributes, such as image sources (src) and alternative text (alt), directly to the Vue instance's data object.

The most significant takeaway from this lab was understanding exactly why this declarative approach is superior to vanilla JavaScript. Instead of writing imperative, multi-step DOM manipulation code (like repeatedly calling document.getElementById() and manually updating innerHTML), Vue allows developers to simply declare the desired state in the template. The framework’s reactivity system automatically tracks dependencies and updates the DOM under the hood whenever the underlying data changes.
